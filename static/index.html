    操作方法
    
  
    
    
    セルをドラッグ / Shift+クリック範囲選択（行番号・列記号のクリックで行・列全体）
    
    
    矢印 / Shift+矢印選択の移動 / 範囲の拡大
    
    
    M / U結合 / 結合の解除
    
    
    R / Shift+R下に行を挿入 / 上に行を挿入
    
    
    C / Shift+C右に列を挿入 / 左に列を挿入
    
    
    Shift+Delete / Ctrl+Delete選択行を削除 / 選択列を削除
    
    
    H選択範囲の下端までを見出し行にする
    
    
    Ctrl+Z / Ctrl+Y元に戻す / やり直し
    
    
    Ctrl+S / Ctrl+Enter保存 / 保存して次へ
    
    
    PageUp / PageDown前の画像 / 次の画像
    
    
    画像: ホイール / ドラッグ拡大縮小 / 移動（F: 全体、W: 横幅、1: 等倍）
    
  
    
  
    見出し（thead）は表の上からの行数で指定します。見出しと本文をまたぐ結合はできません。
